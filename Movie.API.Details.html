Movie API

RESTful API Documentation and Endpoints

Project Overview

A comprehensive RESTful API for a movie database application built with Node.js, Express, and MongoDB. This server-side component provides user management, authentication, and movie data services for frontend applications. The API features secure JWT authentication, comprehensive movie database operations, and a robust favorites management system.

Key Features

  • User Management: Registration, authentication, and profile updates
  • Movie Database: Browse movies with detailed information including genres and directors
  • Favorites System: Add and remove movies from personal favorites list
  • JWT Authentication: Secure API endpoints with JSON Web Tokens
  • Data Validation: Input validation using express-validator
  • CORS Support: Cross-origin resource sharing for frontend applications
  • Password Security: bcrypt for secure password hashing
  • RESTful Architecture: Standard HTTP methods and status codes

Technologies Used

  • Backend Framework: Node.js with Express.js
  • Database: MongoDB with Mongoose ODM
  • Authentication: Passport.js with JWT strategy
  • Password Security: bcrypt for password hashing
  • Validation: express-validator for input validation
  • Development Tools: nodemon, ESLint
  • CORS: Cross-origin resource sharing middleware

API Endpoints

User Authentication

POST /users - User Registration
POST /login - User Authentication

User Management

GET /users - Get all users
GET /users/:Username - Get user by username
PUT /users/:Username - Update user profile
DELETE /users/:Username - Delete user account

Movie Operations

GET /movies - Get all movies
GET /movies/:Title - Get movie by title
GET /movies/genre/:GenreName - Get movies by genre
GET /movies/directors/:DirectorName - Get movies by director

Favorites Management

POST /users/:Username/movies/:MovieID - Add movie to favorites
DELETE /users/:Username/movies/:MovieID - Remove from favorites

Data Models

User Model

  • Username: String (required, min 5 chars, alphanumeric)
  • Password: String (required, bcrypt hashed)
  • Email: String (required, valid email format)
  • FirstName & LastName: String
  • Birthday: Date
  • FavoriteMovies: Array of Movie ObjectIds

Movie Model

  • Title & Description: String (required)
  • Genre: Object with Name and Description
  • Director: Object with Name and Bio
  • Actors: Array of Strings
  • ImagePath: String (movie poster URL)
  • Featured: Boolean flag

Security & Configuration

  • JWT Authentication: Secure token-based user authentication
  • Password Hashing: bcrypt encryption for all user passwords
  • Input Validation: express-validator for server-side data validation
  • CORS Configuration: Allows specific origins including localhost and production domains
  • Error Handling: Comprehensive HTTP status codes (200, 201, 400, 401, 404, 422, 500)
  • Environment Variables: Secure configuration for database and JWT secrets

Development Process

This API was built following RESTful architecture principles and Node.js best practices. The development process included:

  1. Planning API endpoints and data structure design
  2. Setting up Express server with MongoDB integration
  3. Implementing user authentication with Passport.js and JWT
  4. Creating comprehensive CRUD operations for users and movies
  5. Adding data validation and error handling middleware
  6. Configuring CORS for frontend application integration
  7. Testing endpoints with Postman and automated testing
  8. Deployment configuration for production environments
