myFlix Angular Client

myFlix Angular Client - Material Design Movie Database

Project Overview

A sophisticated movie database application built with Angular 10 and Angular Material, providing users with comprehensive information about movies, directors, and genres. This client-side application features modern Material Design UI components and offers users the ability to register, authenticate, and manage their personal favorite movies collection.

Project Goal & Purpose

The primary goal of this project was to build a complete single-page application (SPA) using Angular that demonstrates proficiency in modern frontend development. The application serves as a movie discovery platform where users can explore films, learn about directors and genres, and curate their personal favorites collection through an intuitive, responsive interface.

Technology Stack

  • Frontend Framework: Angular 10.0.14
  • UI Framework: Angular Material 10.2.7
  • Styling: SCSS for advanced styling capabilities
  • HTTP Client: Angular HttpClient for API communication
  • Authentication: JWT token-based security
  • Backend API: Node.js/Express with MongoDB integration
  • Build Tool: Angular CLI 10.0.8
  • Deployment: GitHub Pages hosting

Component Overview

  • WelcomePageComponent: Landing page with login/register options
  • MovieCardComponent: Movie display in card layout with favorite functionality
  • UserRegistrationFormComponent: User registration with validation
  • UserLoginFormComponent: Secure user authentication form
  • UserProfileComponent: User profile management interface
  • Dialog Components: Interactive modals for movie details, director bio, and genre information

API Integration

The application connects to a custom movie API hosted at: https://cinema-center-api-2025-64a4a412d09b.herokuapp.com/

API Endpoints Used:

  • POST /users - User registration
  • POST /login - User authentication
  • GET /movies - Fetch all movies
  • GET /users/:Username - Get user profile
  • PUT /users/:Username - Update user profile

Development Process

This Angular application was built following Angular best practices and Material Design principles:

  1. Project setup with Angular CLI and Material Design integration
  2. Component architecture planning and service layer design
  3. Implementing Angular routing for single-page application navigation
  4. Creating reusable components with TypeScript strong typing
  5. Integrating Angular Material for consistent UI components
  6. Implementing HTTP client services for API communication
  7. Adding JWT authentication and route guards
  8. Building responsive layouts with SCSS styling
  9. Testing and deployment to GitHub Pages

Development & Testing

  • Development Server: ng serve with live reload on port 4200 or 1234
  • Build Process: ng build with production optimization
  • Unit Testing: Karma test runner for component testing
  • E2E Testing: Protractor for end-to-end testing
  • Documentation: TypeDoc for automated code documentation
  • Version Management: NVM for Node.js version control
