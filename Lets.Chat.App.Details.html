Let's Chat App

Screenshot of the Let's Chat App interface

Project Overview

A simple yet powerful chat application built with React Native and Expo, featuring navigation, image sharing, location sharing, and customizable chat backgrounds. The app uses Firebase for real-time messaging and storage, providing users with a seamless communication experience across iOS and Android platforms using Expo's managed workflow.

Key Features

  • Real-time chat using Firebase Firestore
  • Image sharing from camera and photo library with Firebase Storage
  • Location sharing with map preview
  • React Native navigation using @react-navigation/native
  • Customizable chat background colors
  • Splash screen for iOS
  • Expo managed workflow for easy development and deployment
  • Cross-platform compatibility (iOS, Android, and Web)

Technologies Used

  • React Native
  • Expo
  • @react-navigation/native & @react-navigation/native-stack
  • Firebase Firestore
  • Firebase Storage
  • expo-image-picker
  • expo-location
  • react-native-gifted-chat
  • react-native-maps
  • @expo/react-native-action-sheet
  • @react-native-async-storage/async-storage

Development Process

This chat application was built using Expo's managed workflow and follows React Native best practices. The development process included:

  1. Setting up Expo CLI and project structure
  2. Configuring Firebase Firestore and Storage
  3. Implementing navigation with React Navigation
  4. Creating Start screen with name input and background selection
  5. Building Chat component with react-native-gifted-chat
  6. Adding CustomActions for image and location sharing
  7. Setting up Google Maps API for location previews
  8. Testing on multiple platforms (iOS, Android, Web)

Project Structure & Architecture

  • Components: Modular structure with Chat.js, Start.js, and CustomActions.js
  • Navigation: Stack navigation for seamless screen transitions
  • Firebase Integration: Real-time Firestore database with Storage for media files
  • Media Handling: expo-image-picker for camera and photo library access
  • Location Services: expo-location with react-native-maps integration
  • User Interface: react-native-gifted-chat for professional chat experience
  • Cross-Platform: Expo managed workflow supporting iOS, Android, and Web

Usage Instructions

  1. Enter your name and select a background color on the Start screen
  2. Tap "Start Chatting" to enter the chat screen
  3. Use the input field to send messages in real-time
  4. Tap the "+" button to access additional features:
    • Select an image from your photo library
    • Take a photo with the camera
    • Share your current location
  5. Location messages display an interactive map preview
